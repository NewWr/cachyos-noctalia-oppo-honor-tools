# 公开上传内容与本地隐私

[English](PRIVACY.en.md) · [返回 README](../README.md)

## 本包已处理的内容

- 只复制三个已启用插件的源码和明确必需的后端文件，不复制用户配置目录。
- 移除 OPPO 原图片下载路径中的硬编码签名凭据及相应联网代码；控制协议、图标与本地缓存读取保留。
- 将测试中的真实蓝牙地址替换为虚构的、本地管理样例地址；协议 fixture 只保留握手、功能位和匿名 EQ 数据。
- 不包含蓝牙配对数据、私钥、token、个人邮箱、设备序列号、播放日志、个人插件设置、运行 socket/锁、历史备份或编译结果。
- 不包含任何 `.aml`、`.dsl`、`.dat` 或 ACPI 原始转储；某些 ACPI 表可能包含 Windows OEM 产品密钥。
- 保留公开代码归属，如 `osp54`、插件命名空间 `dc`、产品 ID 和固定协议 UUID；这些不是本机认证秘密。
- 上传包没有旧 Git 历史，不会继承可能藏在历史提交中的本地信息。

## 使用时会生成的本地数据

| 工具 | 数据位置 | 可能包含 |
| --- | --- | --- |
| OPPO | `$XDG_RUNTIME_DIR` 内的 `oppo_pods_*` 文件与 socket；未设置时原代码回退 `/tmp` | 蓝牙地址、耳机状态、耳机保存的设备列表 |
| OPPO | `$XDG_CACHE_HOME/noctalia/oppo-pods` | 用户自行放入的设备图片；上传版不自动下载 |
| HONOR 充电 | `/var/lib/honor-battery-profile/profile` | 当前保存的档位 |
| Noctalia | 用户自己的 settings/config | 可能含自定义地址、路径及其他插件的凭据 |

这些位置均不属于仓库。分享问题日志、截图或完整配置前，另行检查设备地址、账户名和其他应用数据。

## 扫描与边界

```bash
python3 scripts/check-public-content.py
```

扫描器检查常见私钥标记、GitHub/云服务凭据、明文凭据赋值、HTTP 内嵌认证、个人绝对路径、OEM key 形状、非虚构 MAC、禁用运行/固件文件及未审核的二进制。保留的 WebP 图标也检查元数据块与可打印内容。报告只显示位置和类别，不回显可疑值。

这是离线启发式检查，不能保证发现所有编码/变形秘密。已对所复制源码做了人工检查；后续新增文件仍需审阅。`.gitignore` 是防误入辅助，不能替代检查或清除已经公开的历史。

充电 sudoers 模板不含用户名：采用组授权，限定三个确切命令。安装后实际组成员属于本机系统状态，勿导出完整 sudoers、用户列表或安全配置到仓库。
