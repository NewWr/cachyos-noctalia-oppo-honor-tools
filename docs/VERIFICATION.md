## 继承的历史结果

已有 OPPO 1.1.2 说明记录了 Free4 标准版/固件 138 的降噪、功能开关、EQ 创建编辑删除、设备通知以及佩戴播放联动验证。本包保留相关代码与协议测试；这些历史说明不能代替此次在真实耳机上重新测量，也不能推导其他型号全部兼容。

HONOR 当前源码使用本机已有的 hwmon、三档 LED、huawei-wmi/BAT0 接口。本次核对源码与接口存在性、编译及只读状态，没有通过 UI 点击切换背光/档位。

## 未验证与使用边界

- 执行环境无法连接正在运行的桌面 Noctalia IPC，因此没有确认新来源在真实桌面加载、布局或点击行为。
- 没有执行 root 安装、开机/唤醒周期、新驱动加载或 Secure Boot 签名。
- 没有对其他电脑、其他 Linux 发行版、其他 BIOS 或其他耳机型号实测。
- 没有重新验证查找提示音；该功能继续标为实验。
- 隐私扫描属于启发式检查；新提交仍需复查暂存内容。

打包过程未修改已安装插件、桌面布局、当前背光或充电配置。此记录对应上传前的检查；公开副本后续发布到用户指定的 GitHub 仓库。
